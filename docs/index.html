ColorBench Leaderboard

Color spaces ranked on real psychophysical datasets — from colour-science and helmlab. Lower score = closer to human vision.

Two boards, on purpose. A space that measures color difference and a space that generates color are judged on different things. Mixing them into one ranking is a category error — so we don't. helmlab isn't one entry either: it competes as metricspace (a learned difference model) on the measurement board and genspace (a synthesis space) on the generation board. Generated by ColorBench · human data from color-perception-datasets ·

Measurement (23 models) = STRESS on 5 independent difference sources — COMBVD unpacked into its components (BFD-P, Leeds, Witt, RIT-DuPont) plus held-out MacAdam 1974 — each model scoring with its own ΔE (metricspace = learned distance; CIEDE2000 / CIE94 = formulas; every colour-science space = Euclidean ΔE); hover a cell for its 95% CI. Overfit Δrank (helmlab only, since it's the one fitted model) = held-out rank minus mean in-sample rank. Generation (21 spaces) is ranked on the full validated human pool — 16 datasets across 5 categories: hue (Hung-Berns, Ebner-Fairchild, Munsell, Xiao), discrimination (MacAdam 1942, Luo-Rigg, Alder, Regan, Hong), 3-D discrimination (Koenderink, Brown 1957, Wyszecki-Fielder, Brown-MacAdam), tolerance (RIT-DuPont, Huang) and spacing (OSA-UCS) — each category weighing equally. No CIELab-referenced engineering metric (gamut-mapping / gradient) is scored: that ruler structurally flatters CIELAB, so it is left off. The greyed Robustness columns are a physics-only gate (not scored): round-trip invertibility and whether a space stays finite across the Rec2020 gamut — measured against the identity and "is this a finite number", so no rival space can bias it (it flags e.g. Yrg's 1e-4 round-trip). The other greyed groups are diagnostic human judges (real data, lightly validated — shown, not scored): Helmholtz-Kohlrausch brightness (Wyszecki 1967 / Zhang 2023 / Sanders 1964 — ρ, ↑ better) and object lightness (Fairchild-Pirrotta), chromatic adaptation (corresponding colours — where CIELAB, having no CAT, scores ~137 ΔE vs OKLab's ~0.3) and observer metamerism (Asano). Color naming (WCS) is omitted — it is space-insensitive (~0.61 for every space). Rank swing = worst minus best rank across the 16 scored datasets — low = robust generalist, high = narrow specialist (the empirical fingerprint of overfitting). Colour-science spaces use their canonical reference implementations.
