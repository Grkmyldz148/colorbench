# ColorBench Leaderboard (GitHub Pages)

Static ranking site for the ColorBench perceptual-measurement leaderboard —
every invertible [colour-science](https://github.com/colour-science/colour)
color space plus **helmlab**, ranked property-by-property on 46 real
psychophysical datasets.

- `index.html` / `style.css` / `leaderboard.js` — the site.
- `leaderboard.json` — the ranking data, regenerated by
  `python3 research/leaderboard.py` (runs every space through `core.human_pool`).

## Enable GitHub Pages

Repo **Settings → Pages → Source: Deploy from a branch → `main` / `/docs`**.
The site publishes at `https://grkmyldz148.github.io/colorbench/`.

## What it measures

Each column is the mean STRESS / error over that property's real human datasets
(lower = closer to human vision):

| Property | Human datasets |
|---|---|
| Difference | COMBVD, MacAdam 1974 |
| Hue | Hung-Berns, Ebner-Fairchild, Munsell, Xiao unique hues |
| Discrimination | MacAdam 1942, Luo-Rigg, Alder, Hong 2025 |
| 3D discrim. | Koenderink 2026, Brown 1957, Brown-MacAdam 1949, Wyszecki-Fielder 1971 |
| Tolerance | RIT-DuPont (Berns 1991), Huang 2012 |
| Spacing | OSA-UCS (the independent, non-Munsell anchor) |

The `overall_rank` is the mean of the per-property ranks — **deliberately not a
single quality score**, because no space is best at everything (the project's
central finding). Colour-science spaces use their canonical reference
implementations; helmlab is the project's generation space (genspace v0.11.1).

Note: this board measures perceptual **measurement** (does the space's geometry
match human vision). It is a different axis from **generation** quality (gamut
smoothness, gradient banding, cusp validity) — helmlab's design target — which
`run.py compare` scores separately.
